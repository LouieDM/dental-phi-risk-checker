# Review Reply PHI-Risk Checker for Dental Practices

A free, single-page tool for US dental offices. Paste a draft reply to a Google review and it highlights wording that may disclose patient information (confirming someone is a patient, naming a treatment, referencing a visit, and similar patterns), so you can fix it before posting.

**Use it:** https://louiedm.github.io/dental-phi-risk-checker/

## How to use
1. Paste your draft reply into the box.
2. Read the highlights: red = likely discloses patient info, yellow = caution.
3. Rewrite. The safe pattern is to thank the reviewer, keep visit details offline, and invite them to call the office.

It flags common risky patterns, not every possible disclosure. A clean result is not a guarantee.

## Privacy: runs entirely in your browser
- All checking is done by client-side JavaScript in `index.html`.
- No backend, no analytics, no cookies, no external scripts. The page stores no replies.
- Text you paste never leaves your device.
